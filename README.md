# VEDA Task 4 – COVID-19 Data Visualization & Storytelling

## 📊 Project Overview

This project was completed as part of the VEDA Technology Data Analytics Internship – Task 4.

The objective of this project is to create meaningful visualizations that communicate trends, patterns, and business insights from a structured COVID-19 dataset using Power BI.

## 🎯 Objective

The project focuses on transforming COVID-19 data into a clear visual story through:

- Regional analysis
- Detailed country-level analysis
- Mortality analysis
- Recovery analysis
- Key insights and recommendations

## 🛠️ Tools Used

- Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis

## 📁 Project Structure

- `VEDA_Task_4_COVID-19_Analysis.pbix` – Power BI report
- `VEDA_Task_4_COVID-19_Analysis.pdf` – Exported visual report

## 📌 Report Pages

### Page 1 – Regional COVID-19 Analysis

This page presents COVID-19 activity across WHO regions and highlights differences in reported cases.

### Page 2 – Detailed Analysis

This page provides detailed country-level analysis of reported COVID-19 cases and related patterns.

### Page 3 – Mortality & Recovery Analysis

This page focuses on:

- Top countries by COVID-19 deaths
- COVID-19 recoveries across WHO regions

### Page 4 – Key Insights & Recommendations

This page summarizes the major findings and provides recommendations based on the analysis.

## 🔍 Key Insights

### 1. Mortality Concentration

COVID-19 deaths were highly concentrated in a small number of countries, indicating significant differences in reported mortality.

### 2. Recovery Pattern

Reported recoveries varied substantially across WHO regions, reflecting differences in the scale of reported cases and outcomes.

### 3. Key Recommendation

Focus on high-burden countries and regions for deeper analysis, resource planning, and targeted public-health interventions.

## 📈 Data Visualization Approach

The report uses Power BI visualizations to communicate the findings through:

- Bar charts
- Country-level comparisons
- Regional comparisons
- Mortality analysis
- Recovery analysis
- Insight and recommendation panels

Each major visual is paired with a concise takeaway to support a clear data storytelling approach.
